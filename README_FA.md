# راهنمای فارسی Ultroid

> این فایل، راهنمای فارسی پروژه Ultroid است. Ultroid یک UserBot تلگرام مبتنی بر Python و Telethon است. این پروژه با یک ربات معمولی Bot API تفاوت دارد و با نشست (Session) حساب کاربری کار می‌کند.

## وضعیت فارسی‌سازی

این نسخه در شاخه `persian` نگهداری می‌شود. در این مرحله راهنمای فارسی نصب و پیکربندی اضافه شده است؛ ترجمهٔ کامل متن دستورات و پیام‌های پلاگین‌ها هنوز انجام نشده و نیازمند بررسی جداگانهٔ کد هر پلاگین است.

## پیش‌نیازها

- Python نسخهٔ 3.10 یا بالاتر
- Git
- دسترسی به ترمینال
- یک پایگاه دادهٔ پشتیبانی‌شده، مانند Redis یا MongoDB یا SQLDB
- اطلاعات API تلگرام و نشست حساب، مطابق مستندات پروژه

## دریافت پروژه

```bash
git clone https://github.com/iran13570216-bit/Ultroid.git
cd Ultroid
git checkout persian
```

## نصب وابستگی‌ها

ساخت محیط مجازی:

### ویندوز (PowerShell)

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

اگر پروژه در فایل‌های راهنمای اصلی خود وابستگی‌های اختیاری جداگانه‌ای معرفی کرده است، فقط در صورت نیاز و پس از بررسی همان فایل‌ها آن‌ها را نصب کنید.

### لینوکس

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## پیکربندی

1. فایل نمونهٔ تنظیمات `.env.sample` را بررسی کنید.
2. یک نسخه با نام `.env` بسازید.
3. مقادیر موردنیاز پروژه را در آن وارد کنید.
4. از قرار دادن فایل `.env`، رشتهٔ نشست (Session String)، رمزها یا کلیدهای API در GitHub خودداری کنید.

متغیرهای پایگاه داده که در راهنمای upstream ذکر شده‌اند:

- `REDIS_URI` و در صورت نیاز `REDIS_PASSWORD`
- یا `MONGO_URI`
- یا `DATABASE_URL`

همهٔ این گزینه‌ها را هم‌زمان تنظیم نکنید؛ مطابق پیکربندی مورد استفادهٔ خودتان عمل کنید.

## اجرای برنامه

دستور اجرای دقیق به سیستم‌عامل و نسخهٔ پروژه بستگی دارد. راهنمای upstream برای اجرای محلی، اجرای ماژول را در ویندوز و اسکریپت startup را در لینوکس معرفی می‌کند. پیش از اجرا، فایل‌های راه‌اندازی همین شاخه را بررسی کنید.

## امنیت حساب

- رشتهٔ نشست معادل دسترسی ورود به حساب تلگرام شماست؛ آن را با هیچ‌کس به اشتراک نگذارید.
- نشست را در مخزن عمومی، اسکرین‌شات، پیام یا فایل گزارش قرار ندهید.
- برای پروژه یک حساب آزمایشی در نظر بگیرید و ابتدا روی آن آزمایش کنید.
- از ارسال انبوه، پیام ناخواسته و هر رفتاری که موجب محدودیت حساب یا نقض قوانین تلگرام می‌شود خودداری کنید.
- UserBotها از حساب شخصی استفاده می‌کنند؛ استفاده از آن‌ها با مسئولیت خودتان است.

## دستورات و راهنما

برای مشاهدهٔ فهرست دستورات در زمان اجرا از دستور راهنمای داخلی خود پروژه استفاده کنید. نام و پیشوند دستورات ممکن است با تنظیمات یا نسخهٔ نصب‌شده تفاوت داشته باشد.

## مشارکت در فارسی‌سازی

برای تکمیل ترجمه:

1. متن‌های قابل‌نمایش به کاربر را از کد و پلاگین‌ها استخراج کنید.
2. متن فارسی را در فایل‌های زبان متمرکز نگه دارید.
3. کلیدهای دستورات، نام متغیرها، callbackها و شناسه‌های داخلی را بدون تغییر حفظ کنید.
4. متن‌های دارای قالب‌بندی، placeholder و escape را با همان ساختار ترجمه کنید.
5. پس از هر تغییر، دستورات و پلاگین مربوط را آزمایش کنید.
